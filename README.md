# IN3030 - Efficient Parallel Programming (2022)

My solutions to the five mandatory assignments of IN3030 at the University of Oslo, written in Java.
Each assignment compares a sequential and a parallel (multi-threaded) version and measures the speedup;
the PDF in each folder is the report with the measurements.

| Folder | Topic |
|---|---|
| `PP_Mandatory_1` | Finding the k largest numbers in an array (partial insertion sort) |
| `PP_Mandatory_2` | Matrix multiplication, plain and with transposed matrices |
| `PP_Mandatory_3` | Sieve of Eratosthenes and prime factorization |
| `PP_Mandatory_4` | Radix sort |
| `PP_Mandatory_5` | Convex hull |

The `precode` files were provided by the course.
